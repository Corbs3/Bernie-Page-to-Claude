# Bernie

Bernie fetches any web page and carries it to Claude in one click.

## How to use
1. Click Bernie in the toolbar, pick "Whole page" or "Selected text".
2. Choose what to ask Claude (or "Just the page").
3. Press **Send to Claude**. A new Claude chat opens with the page pasted in.
4. Check it, add your question if you like, then press Enter.

Also works from the right-click menu and the shortcut **⌥ Shift C**.

## Mac app option
- Pick **Mac app** under "Open in" (needs the Claude desktop app installed).
- Short pages go straight into the app's message box.
- Long pages (over about 13,000 characters) are copied instead. The app opens with your prompt, then press **⌘V**.
- The first time, Chrome asks to open Claude. Tick "Always allow" to skip this next time.

## Paste into a chat you already have
- Pick **Paste myself** under "Open in". The button changes to **Copy for pasting**.
- Go to your Claude chat (browser or app) and press **⌘V**.
- Right-click and the shortcut show a green tick on Bernie when it's copied.

## Good to know
- It never sends anything by itself. You always press Enter.
- Some pages can't be read, such as Chrome settings, the Web Store and Google Docs (which draws its text in a way extensions can't read).
- Very long pages are trimmed at 200,000 characters.

## Install for testing
1. Download this repo and go to `chrome://extensions`
2. Turn on **Developer mode**, click **Load unpacked** and pick the folder
